# Theo Armour Pages — AI Agent Instructions

## What This Repo Is

My digital commonplace book: notes, quotations, links and reflections on what I read, watch and think about. Published at https://theo-armour.github.io/pages. Content is GitHub-flavored Markdown — this is not a code repo.

**This repo is public.**

## Organization

- Numbered folders `01-general-reference/` … `13-technology-applied-sciences/` follow Wikipedia's top-level categories. See [0-categories.md](0-categories.md) and [000-topics.md](000-topics.md).
- `00-` folders are cross-cutting: commons, inspirations, journal, snippets.
- `!-new/` — inbox for notes not yet filed.
- People get a file or folder under their category, e.g. `10-philosophy-and-thinking/philosophers/Shigehiro-Oishi/`.
- [0-pages-agenda.md](0-pages-agenda.md), [0-journal.md](0-journal.md) — priorities and dated notes.
- [index.html](index.html) — TooToo instance that browses this repo (generated; treat as read-only). Per-install settings live in `tootoo.config.js`.

## Conventions for Edits

- **Quotations stay exact.** Much of this is other people's words. Don't reword, tidy or "correct" quoted text, and keep its source link with it.
- **Mine versus theirs.** Keep my own comments visibly separate from quoted material; don't blend the two.
- **Filing.** Put a new note in the Wikipedia category it best fits; if unsure, put it in `!-new/` and tell me. Before creating a file for a person or topic, search for an existing one.
- **Names.** Words are joined by hyphens. Files and folders named after a person capitalize each part of the name (`Jacques-Lacan.md`, `John-Trauth/`); other new files are lowercase. Dated files use a `YYYY-MM-DD` prefix. Don't rename existing files — published links point at them.
- **Nothing private.** Never copy material from my private repos (agenda, journals, people notes) into this one.
- Notes are short and informal — fragments and bare links are normal here. Fix typos; propose anything bigger.
